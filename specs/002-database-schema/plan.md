# Implementation Plan: Database Schema & Migrations

**Branch**: `002-database-schema` | **Date**: 2026-07-31 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-database-schema/spec.md`

## Summary

Create a PostgreSQL schema with 8 tables (tenants, users, sessions, properties,
clients, prospections, contacts, audit_log) via forward-only golang-migrate
SQL migrations. sqlc generates typed Go from SQL queries -- no ORM.
Multi-tenant isolation enforced via `tenant_id` FK + index on every
tenant-scoped table. The schema supports LGPD-sensitive client/property data
with audit logging. The MVP is single-tenant, single-admin but the schema ships
`tenant_id` from day one for future-proof encanamento.

## Technical Context

**Language/Version**: Go 1.26 (go.mod minimum)

**Primary Dependencies**:
- `golang-migrate/migrate/v4` -- forward-only SQL migrations
- `sqlc` (v1.31.1) -- SQL-to-Go code generation
- `github.com/jackc/pgx/v5` -- Postgres driver (sqlc pgx recipe)
- `github.com/google/uuid` -- UUID v7 generation for primary keys

**Storage**: PostgreSQL 16+ (via DATABASE_URL)

**Testing**: `go test -race -coverprofile` (85% gate); integration tests
against real Postgres (CI service container); `testcontainers-go` optional for
local integration tests.

**Target Platform**: Linux server (production), macOS/Linux dev (local)

**Project Type**: web-service (server-rendered monolith, Go + HTMX + Postgres)

**Performance Goals**: Schema-level only: indexed `tenant_id` on all
tenant-scoped tables for O(log n) tenant filtering. No application-level
performance targets in this spec.

**Constraints**:
- Forward-only migrations (Constitution VI): no destructive changes without ADR
- 85% test coverage on hand-written Go code (sqlc-generated excluded)
- No ORM (sqlc is source of truth)
- LGPD: PII fields documented in data contract (spec.md)

**Scale/Scope**: 8 tables, ~15-20 sqlc queries, 1 initial migration file
(up + down).

### Source Code (repository root)

```text

├── 000001_initial_schema.up.sql   # CREATE TABLE for all 8 tables
└── 000001_initial_schema.down.sql # DROP TABLE (reverse order)

internal/
├── db/
│   ├── queries/                   # SQL queries (sqlc input)
│   │   ├── tenants.sql
│   │   ├── users.sql
│   │   ├── sessions.sql
│   │   ├── properties.sql
│   │   ├── clients.sql
│   │   ├── prospections.sql
│   │   ├── contacts.sql
│   │   └── audit_log.sql
│   ├── models.go                  # sqlc generated (table structs)
│   ├── *.sql.go                   # sqlc generated (query functions)
│   ├── db.go                      # sqlc generated (DBTX interface)
│   └── db_test.go                 # Integration tests (real Postgres)
```

**Structure Decision**: Single Go binary layout. Migrations in `migrations/`
(golang-migrate convention). sqlc queries in `internal/db/queries/`, generated
code in `internal/db/` (gitignored -- regenerated by `make sqlc`). Tests in
`internal/db/db_test.go` use real Postgres via DATABASE_URL (CI service
container provides Postgres 16).
